# O jogo

Jogo de survival horror, onde o protagonista está preso em um verdadeiro pesadelo distópico envolvendo androides e seres humanos altamente integrados à tecnologia.

## Principais inspirações

- Resident Evil
- Silent Hill
- CyberPunk 2077
- Parasite Eve
- Junji Ito
- Akira Yamaoka

## Características técnicas

- Câmera terceira pessoa fixa
- Renderização 3D simples
- Low Poly

## Objetivo

Evoluir na história através de níveis com progressão de dificuldade. Para progredir o jogador deve coletar recursos, fazer gerenciamento, solucionar quebra-cabeças e derrotar inimigos chave. O objetivo final é chegar até o lugar seguro, fugindo do pesadelo CyberPunk.
